# Right panel synchronization issue
_Exported on 11/19/2026 at 15:13:39 PST from Cursor (3.31.11)_

---

**User**

When an item representing a folder is selected in the right-hand panel, it triggers synchronization with the items in the tree located in the left-hand panel. 
This is incorrect; selecting an item in the right-hand panel should not trigger synchronization with the tree, especially since the folder currently displayed at the top of the right panel is different from the one being selected in the tree—this is highly confusing for the user.

Clicking an item in the right panel no longer changes the tree. The changes type-check and lint cleanly, but I haven't run the app to click through it.

**What was happening:** a right-panel click went through the same path as a tree click. It expanded the clicked folder and all its ancestors, and the tree highlighted that folder. The right panel stayed on the pinned folder, so the two panels showed different folders.

**What changed:**
- **`a-bookmarks-atoms.ts`:** added `selectionPanelAtom` to record whether the last selection came from the tree or the right panel. Added `isTreeSelectedAtom`, which highlights a row in the tree only when the selection came from the tree.
- **`a-bookmarks-actions.ts`:** `clickItemAtom` records the source panel. A plain click in the right panel now only sets the selection and no longer expands anything. Ctrl- and Shift-clicks keep working, and the right panel stays on its current folder as before.
- **`tree-panel.tsx`:** rows use `isTreeSelectedAtom`, so a right-panel selection no longer highlights anything in the tree.

**Unchanged on purpose:**
- Tree clicks and arrow-key navigation still expand and select in the tree.
- Double-clicking a folder in the right panel still opens it and reveals it in the tree. That is an explicit "open", not a plain selection. If you want it to stay decoupled too, tell me and I'll change it.

One side effect: while the selection is in the right panel, the tree shows no highlighted row. It shows the highlight again once you click in the tree.
