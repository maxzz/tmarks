**Export**
- Export works on the same items as Cut, Copy, and Delete. If you right-click a selected item, it exports the whole selection. Otherwise it exports only the item you right-clicked.
- It writes one Netscape `.html` file, the same format as "Save bookmarks". Each selected folder comes with everything inside it, and items nested inside another selected folder are skipped.
- A single item is named after its title (for example `Work.html`). Several items get `bookmarks-<date>.html`.

**Selection**
- Shift and Ctrl clicking already existed, but they didn't match Explorer. Ctrl+Shift click now adds a range to the current selection instead of replacing it.
- The click rules now live in `b-selection-logic.ts` and are covered by tests.

**Menu scope change**
- The context menu used to act on whichever panel was clicked last. Now a right-click acts on the selection of the panel the row belongs to. This also applies to Cut, Copy, and Delete from the menu. Keyboard shortcuts still use the last-clicked panel.

**Decisions for you**
- I chose one file for multiple items. If you want one file per item, that's a small change.
- Items selected in the right panel stay selected after you switch folders, as your earlier notes asked. Export and Delete include them even when they're out of view, so a hidden item can end up in an export.
