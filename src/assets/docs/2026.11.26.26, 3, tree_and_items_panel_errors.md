Both errors are fixed. The app type-check now passes with no errors.

**Cause:** `ScrollArea`'s `viewportProps` prop was typed as Radix's viewport props only. Those don't include `data-*` attributes, so `{ "data-dnd-scroll": "" }` failed TypeScript's excess-property check in both `tree-panel.tsx:24` and `items-panel.tsx:37`.

**Fix:** In `src/ui/shadcn/scroll-area.tsx`, I widened the type of `viewportProps` to also accept any `data-*` key:

```ts
viewportProps?: ComponentPropsWithoutRef<typeof Prim.Viewport> & { [key: `data-${string}`]: string | undefined };
```

Neither call site needed to change. The `data-dnd-scroll` attribute still reaches the viewport element at runtime, since `viewportProps` is spread onto `Prim.Viewport` as before.
