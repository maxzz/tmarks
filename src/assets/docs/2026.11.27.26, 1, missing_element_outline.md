Is it possible to implement the highlighting of a selected element using an `outline` that is offset 1 pixel inward?

---

**Cursor**

Yes. Use a negative `outline-offset` of `-1px`. That moves the outline inside the element's border edge, so it stays within the row's box and the scroll viewport won't clip it.

In Tailwind it would look like this:

```tsx
"outline outline-1 -outline-offset-1 outline-border ..."
```

Plain CSS equivalent: `outline: 1px solid var(--border); outline-offset: -1px;`

The ring I used last turn also sits inside the box, so either approach fixes the clipping. The outline version keeps the `outline` classes you already had. Should I switch the row to it?
