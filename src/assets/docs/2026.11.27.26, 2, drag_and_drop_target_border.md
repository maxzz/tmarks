**The fix**

`DropIndicator` is now a plain `div` placed at its exact position on every pointer move, with no spring and no `AnimatePresence`. Only one shape exists at a time, and it can't trail the pointer. The `Indicator` component is gone. The one trade-off is that the indicator now appears and disappears without a fade.

```48:69:c:\y\w\2-web\0-stack\2-editors\tmarks\src\components\2-main\4-dnd\5-dnd-ui.tsx
/**
 * A line for `before` and `after`, a box for `into` and `end`. It is placed at its exact position on every pointer
 * move, with no animation and no remount, so it never trails the pointer and only one shape is on screen at a time.
 */
function DropIndicator() {
    const target = useAtomValue(dropTargetAtom);
    if (!target) {
        return null;
    }

    const isLine = target.placement.kind === "before" || target.placement.kind === "after";
    return (
        <div
            className={isLine
                ? "fixed rounded-full bg-primary pointer-events-none z-40"
                : "fixed rounded-md border-2 border-dashed border-primary bg-primary/5 pointer-events-none z-40"
            }
            style={indicatorGeometry(target)}
        />
    );
}
```

The file also had a typo in the box class (`rounded border-2 1border-dashed`). I corrected it to `rounded-md border-2 border-dashed` as part of this rewrite.
